# ⚽ СпортСтат

Футбольная статистика для турниров 5x5.

## 🚀 Функционал

- ✅ Список турниров
- ✅ Детали турнира (таблица, матчи)
- ✅ Общая статистика игроков
- ✅ ТОП-10 бомбардиров
- ✅ ТОП-10 по PEI
- ✅ Зал славы
- ✅ Галерея игроков

## 🛠️ Технологии

- HTML / CSS / JavaScript
- Supabase (PostgreSQL)
- Vercel / Netlify
