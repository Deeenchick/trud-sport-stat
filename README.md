# ⚽ СпортСтат

Футбольная статистика для турниров 5x5.

## 🚀 Функционал

- ✅ Список турниров
- ✅ Детали турнира (таблица, матчи)
- ✅ Общая статистика игроков
- ✅ ТОП-10 бомбардиров
- ✅ ТОП-10 по PEI
- ✅ Зал славы
- ✅ Галерея игроков

## 🛠️ Технологии

- HTML / CSS / JavaScript
- Supabase (PostgreSQL)
- Vercel / Netlify

## 🔧 Настройка

1. Заменить `SUPABASE_URL` и `SUPABASE_ANON_KEY` в `js/supabase.js`
2. Залить на Netlify / Vercel

## 📱 Адаптивность

- Десктоп: 4-5 колонок
- Планшет: 2-3 колонки
- Телефон: 1-2 колонки

## 🏆 Автор

Создано для турниров по футболу 5x5.
